# GradCredit



GradCredit is a modern education loan platform that helps students compare education loan offers from multiple banks and complete the application process online.

- Student Registration & Login
- Education Loan Application
- Co-Applicant Management
- Eligibility Assessment
- Collateral & Non-Collateral Loans
- Document Upload & Verification
- Education Loan Calculator
- Admin Dashboard
- Counselor Dashboard
- Partner Bank Comparison
- Study Abroad Information

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase



```bash
npm install
npm run dev
```



```bash
npm run build
```
